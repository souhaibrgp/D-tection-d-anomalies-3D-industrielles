🧠 Projet Deep Learning — Détection d'anomalies 3D

CMAD-Net

Cross-Modal Attention Detection Network
Détection d'anomalies 3D par Reverse Distillation avec attention croisée entre RGB et Depth.

🔬 ViT-B/16 DINOv2 ⚡ Cross-Modal Attention 🎓 Teacher-Student 📊 MVTec 3D-AD 🔄 Reverse Distillation
📐 PyTorch + timm 🖼️ 10 catégories 📏 224×224 🌱 Seed 42 ⚡ CUDA / CPU
📋 Slide 2 — Problématique & Approche

Contexte, Problème & Solution

🏭

Problème Industriel

Détecter des défauts rares et imprévisibles (fissures, contaminations, trous, déformations) sur des objets 3D en production. Les anomalies sont infiniment variées → impossible de toutes les apprendre.

🎯

Approche Non-Supervisée

On entraîne uniquement sur des échantillons normaux. Le modèle apprend ce qui est "normal". En inférence, tout ce qui dévie du normal appris est signalé comme anomalie, sans jamais avoir vu de défaut.

🔑

Innovation CMAD-Net

3 innovations clés :

1. Cross-Modal Attention — Fusion intelligente RGB ↔ Depth
2. Reverse Distillation — Teacher-Student pour détection
3. Adaptive Fusion — Poids par catégorie d'objet
📦

Dataset : MVTec 3D-AD

Benchmark standard — 10 catégories d'objets réels avec images RGB + scans 3D. Chaque catégorie a un train set (normaux), validation et test (normaux + anomaux avec ground truth).

🥯 bagel🔌 cable_gland 🥕 carrot🍪 cookie 🪵 dowel🧽 foam 🍑 peach🥔 potato 🪢 rope🛞 tire
📐

Données Multi-Modales

RGB Image couleur (PNG) → resize 224×224, normalize ImageNet
XYZ/Depth Nuage de points 3D (TIFF) → extraction canal Z
Normal Map Sobel (k=3/5/7 selon catégorie) → surface normals
GT Mask Masque binaire des anomalies (test seulement)
💡 Paradigme Reverse Distillation

Un Student apprend à reconstruire les features du Teacher sur les normaux. En inférence, les anomalies ne sont pas reconstruites → discordance = anomalie.

🔒 ViT-B/16 DINOv2 — Backbone

Modèle vit_base_patch16_224.dino via timm. Totalement gelé — sert de feature extractor universel. Poids partagés entre RGB et Depth. Forward hooks aux blocs 3, 6, 9, 12.

768 dim 14×14 ~86M params gelés

⚡ CMCA — Cross-Modal Cross-Attention

Module central. Q(RGB) × K,V(Depth) → RGB enrichi. Q(Depth) × K,V(RGB) → Depth enrichi. Résiduel + LayerNorm + FFN (256→1024→256, GELU).

8 têtes 4 niveaux 0.1 dropout

🗄️ Memory Bank — Statistiques normales

Composant non-paramétrique. Stocke mean et std des features normales (concaténation 4 niveaux FPN → 1024 canaux). Détection par distance pseudo-Mahalanobis : ((x − μ) / σ)².

Non-paramétrique CPU storage

🛡️ FP Filter — Suppression faux positifs

Apprend un masque de régions naturellement actives via un bg_estimator (Conv 3×3→128→64→1 + Sigmoid). Paramètres apprenables : adaptive_threshold et suppression_factor.

Conv2d bg_estimator Seuillage adaptatif
🔍 Détection d'anomalies par Memory Bank

anomaly_map = mean(((features − μ) / σ)²) — Distance pseudo-Mahalanobis normalisée. Sur les normaux → features proches de μ → map ≈ 0. Sur les anomalies → features éloignées → map ↑. Le FP Filter supprime les faux positifs : filtered = map × (1 − supp × bg_score). Les maps sont fusionnées par AdaptiveFusion (poids softmax par catégorie).

Entraînement : 3 Phases par Catégorie

PHASE 1 — ENTRAÎNEMENT FPN + CMCA

Aligner les features RGB et Depth

On entraîne le FPN et le CMCA pour que les features cross-modales soient cohérentes (Consistency) et diversifiées entre niveaux (Diversity).

📋 CONFIGURATION
Entraînés FPN_rgb, FPN_depth, CMCA
Gelé ViT, FP Filter, Fusion
Données Train set (normaux), batch=16
Epochs 100 (local) / 50 (Kaggle)
Optimizer AdamW (lr=1e-4, wd=1e-4)
Scheduler CosineAnnealingLR
📉 LOSSES
# Consistency : aligner RGB ↔ Depth ℒ_cons = mean(1 - cos_sim(feat_rgb, feat_depth)) # Diversity : décorréler les niveaux FPN ℒ_div = ‖F_norm_iT × F_norm_j‖² # Total : ℒ = 1.0 × ℒ_cons + 0.1 × ℒ_div
Consistency — Force l'alignement RGB↔Depth sur les normaux
Diversity — Empêche la redondance entre niveaux FPN

Supprimer les faux positifs

Entraîne le FP Filter et la Fusion sur le validation set. La loss minimise les scores d'anomalies sur les normaux (ils devraient être à 0).

class CMADNet(nn.Module): def extract_features(self, rgb, depth): # 1. Backbone ViT (gelé) vit_rgb = self.encoder(rgb) vit_depth = self.encoder(depth) # 2. FPN séparé par modalité fpn_rgb = self.fpn_rgb(vit_rgb) fpn_depth = self.fpn_depth(vit_depth) # 3. CMCA — enrichissement cross-modal feat_rgb, feat_depth = self.cmca( fpn_rgb, fpn_depth) return feat_rgb, feat_depth

🛡️ fp_filter.py — Suppression Faux Positifs

class FPFilterModule(nn.Module): # bg_estimator: Conv(1024→128→64→1) + Sigmoid # adaptive_threshold (init 0.5) # suppression_factor (init 0.3) def forward(self, anomaly_map, features): bg_score = self.bg_estimator(features) # Suppression du fond filtered = anomaly_map * ( 1 - supp * bg_score) # Seuillage adaptatif filtered = ReLU(filtered - offset) return filtered

📏 Métriques Expliquées

IMG I-AUROC — L'image contient-elle une anomalie ? (classification binaire)
PIX P-AUROC — Chaque pixel est-il anomal ? (segmentation)
PIX AUPRO@FPR — Per-Region Overlap à FPR max (5%, 10%, 30%)
IMG I-AP / I-F1 — Average Precision & F1-Score max
🔍 Analyse des résultats

P-AUROC très élevé (0.958 moy.) : excellente segmentation pixel-level. Meilleures catégories : rope (0.953 I-AUROC) et bagel (0.936). I-AUROC plus variable (0.54–0.95) car la classification image est plus sensible aux faux positifs globaux. La fusion adaptative ajuste automatiquement le ratio RGB/Depth selon l'objet.

Conclusion & Perspectives

✅

Ce qui a été réalisé

✔ Architecture multi-modale complète (RGB + Depth 3D)
✔ Paradigme Teacher-Student Reverse Distillation fonctionnel
✔ Cross-Modal Attention (CMCA) pour fusion intelligente
✔ Pipeline d'entraînement 2 phases automatisé
✔ Évaluation complète sur 10 catégories MVTec 3D-AD
✔ P-AUROC moyen 0.958 — excellente segmentation pixel
📊

Points Forts

🏆 P-AUROC 0.982 (rope) — segmentation quasi-parfaite
🏆 I-AUROC 0.953 (rope) — excellente classification
🏆 AUPRO@30% 0.922 (carrot) — localisation précise
📉 Convergence stable en ~75 epochs
🔀 Fusion adaptative par catégorie automatique
⚠️

Limitations Identifiées

⚡ I-AUROC variable (0.54–0.95) selon la catégorie
⚡ P-AP faible → précision de segmentation fine à améliorer
⚡ Catégories complexes (potato, foam) plus difficiles
⚡ Temps d'entraînement élevé (100 epochs × 10 catégories)
🔮

Améliorations Possibles

1. DINOv2 ViT-L/14 — Backbone plus puissant (1024 dim)
2. Multi-scale Student — Entrées multi-niveaux au lieu de P4 seul
3. Augmentation de données — CutPaste, rotation, bruit pour robustesse
4. Post-traitement avancé — Adaptive Gaussian + seuillage par catégorie
5. Résolution plus élevée — 448×448 pour une meilleure granularité
6. Few-shot learning — Intégrer quelques exemples anomaux
🎯 Message Principal

CMAD-Net démontre que la fusion cross-modale RGB+Depth combinée avec la Reverse Distillation est une approche viable pour la détection d'anomalies 3D non-supervisée. Le P-AUROC moyen de 0.958 confirme une excellente capacité de segmentation pixel-level des défauts.
